# FinSight design references

The `web design/` and `mobile design/` folders are the user-provided visual references for the current web and Android clients. They contain 10 screen images, matching static HTML mockups, and a `DESIGN.md` file for each platform. The HTML is reference material; the running products are in `web/` and `mobile/`.

Use the references for layout, spacing, typography, colors, and component patterns. For screens absent from the references, extend those same patterns. Use the repository's FinSight name and current product logo where a mockup differs. Do not copy mockup account details, remote image URLs, or demo behavior into the running apps.

Email and password values embedded in the static mockups were removed before tracking these files. The original screen images were retained as supplied.
