# FinSight design references

The local `mobile design/` folder is the user-provided V3 reference for Android. Its numbered UI and popup folders contain screen images and static HTML, with a screen registry and flow map at the folder root. It is ignored by Git at the owner's request and must remain available locally while implementing the mobile app. The separate `web design/` reference is unchanged. The running products are in `mobile/` and `web/`.

Implement the numbered mobile screens and flows against their supplied images, HTML and flow map. Use the new logo copied from `mobile design/Logo/` into `mobile/assets/`. Do not introduce extra visual patterns, demo account details, remote image URLs or mock behavior. Where a pictured behavior has no matching API, show only truthful available behavior and record the gap.

The former mobile mockups were removed from the Git index. Ignoring this folder does not erase its old versions from repository history.
